# pakar-gizi-skripsi
Aplikasi web yang mengombinasikan algoritma Harris Benedict dan CF untuk mengukur kebutuhan kalori harian serta menganalisis faktor risiko obesitas berdasarkan pola hidup pengguna. Aplikasi web ini menyajikan analisis kesehatan yang berisikan skor IMT, rekomendasi bahan pangan, pantangan, serta panduan kalori yang disesuaikan secara personal.
